# /opposing-counsel-review

Review the selected contract from the opposing party's perspective. Work
through the standard positions in [the negotiation playbook](references/playbook.md)
and the fallback language in ./references/positions.md.

## Steps

1. Read the selected documents and the playbook.
2. For each clause, state the position the other side is likely to take.
3. Draft negotiation points the lawyer can use.

## Related skills

- Pair this with the other skills in the suite for a full review.

## Output

Produce a summary the lawyer can review before the negotiation.
